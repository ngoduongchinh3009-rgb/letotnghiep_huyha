Ảnh vừa chụp

Gửi lời chúc cho HuyHa

Mỗi người gửi một lời chúc + ảnh kỷ niệm. HuyHa sẽ xem được tất cả trong “Wall” phía dưới.

Thiết lập (admin): Firebase + Cloudinary + mã mời

1) Tạo Firebase Project → bật Firestore + Storage.

2) Tạo Web App, copy firebaseConfig rồi dán vào biến FIREBASE_CONFIG trong file index.html.

3) Chọn mã mời (passcode), rồi tạo SHA-256 hex và dán vào PASSCODE_HASH.

Gợi ý nhanh (Console):

(async()=>{const b=await crypto.subtle.digest('SHA-256',new TextEncoder().encode('MA_MOI'));console.log([...new Uint8Array(b)].map(x=>x.toString(16).padStart(2,'0')).join(''))})()

4) Tạo Cloudinary account → tạo Upload preset dạng Unsigned, rồi điền CLOUDINARY.cloudName + CLOUDINARY.uploadPreset trong index.html.

Giới hạn ảnh: vì UI Cloudinary có thể không hiện mục giới hạn trong preset, web sẽ tự giới hạn và tự nén ảnh xuống ~2MB trước khi upload để an toàn và nhanh trên mobile.

5) Firestore rules mẫu (chặn spam cơ bản):

match /wishes/{id} { allow read: if true; allow create: if request.resource.data.passcodeHash == \"<PASSCODE_HASH>\"; allow update, delete: if false; }

Lưu ý: Dự án này dùng Cloudinary để lưu ảnh, nên không cần Firebase Storage/billing.

Lưu ý: Đây là chống spam cơ bản (ai xem được source vẫn thấy hash). Muốn chặt hơn cần Auth hoặc backend.

Link này chỉ để xem Wall.
Hướng dẫn vận hành (HuyHa) / GitHub Pages

Link Wall: dùng chính link GitHub Pages hiện tại. Kéo xuống “Wall lời chúc”.

Chụp & gửi: người dùng chụp ảnh → preview → tick “Dùng ảnh vừa chụp” → nhập lời chúc + mã mời → Gửi.

Xem ảnh lớn: bấm vào thumbnail trong Wall.

Mobile vẫn thấy bản cũ: Safari/Chrome hay cache. Thử refresh mạnh hoặc mở tab ẩn danh.
